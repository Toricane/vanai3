🔬 Methodology

Semantic Embeddings: Each text response was converted to a 3,072-dimensional vector using OpenAI's text-embedding-3-large model, capturing semantic meaning.

Dimensionality Reduction: t-SNE algorithm reduced high-dimensional embeddings to 3D coordinates while preserving local structure and clustering patterns.

Optimal Clustering: K-Means clustering with silhouette score optimization automatically determined the most meaningful thematic groupings.

Frequency Visualization: Point sizes represent response frequency (cube root scaling for volume), positioned at cluster centroids with hover details.

Interactive Exploration: Each 3D visualization supports rotation, zooming, and hover inspection of original response text and cluster information.
